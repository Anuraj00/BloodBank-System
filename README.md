# Blood Bank Management System 🩸

## 📌 Overview

A web-based application to manage blood donors, blood availability, and requests in real-time.

---

## 🚀 Features

* Real-time blood availability tracking
* Donor and recipient management
* Dashboard with data visualization
* Admin panel for control

---

## 🛠️ Tech Stack

* Python (Django)
* HTML, CSS, JavaScript
* SQLite / PostgreSQL
